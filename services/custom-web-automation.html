What is it?

Custom web automation uses tools such as Playwright or Selenium to control a real browser with code, so repetitive tasks like logging in, filling forms, clicking through multi-step workflows and downloading reports run automatically and consistently.

Overview

Many business processes still depend on someone clicking through the same web pages every day: downloading reports from a portal, entering records into a web form, checking statuses across accounts. These tasks are ideal for automation.

My background includes QA test automation with Selenium and Playwright, so I build browser automation that waits correctly for pages, handles errors and logs what it did. Credentials are never hardcoded; they are read from environment variables or a local config file that stays on your machine.

Business use cases

  • Scheduled report downloads from web portals and dashboards
  • Bulk form submission and data entry into web applications
  • Status checks across many accounts, orders or shipments
  • Screenshot and page-change monitoring
  • End-to-end workflow automation combining scraping and data processing

Example deliverables

Frequently asked questions

Can the automation log in to my accounts?

Yes, for accounts you own or are authorised to use. Credentials stay on your machine in environment variables or a local config file.

Playwright or Selenium: which do you use?

Playwright for most new projects because of its built-in auto-waiting and speed, and Selenium where an existing setup or specific browser support requires it.

Can it run on a schedule?

Yes. Scripts can be scheduled with Windows Task Scheduler, cron, or a cloud runner, depending on your environment.
