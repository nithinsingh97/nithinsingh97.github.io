Data Cleaning and Excel Automation

What is it?

Data cleaning fixes the problems that make a dataset hard to use, such as duplicates, inconsistent formats, missing values and badly split columns. Excel automation uses Python to repeat spreadsheet tasks like merging, reformatting and reporting automatically instead of by hand.

Overview

Raw data rarely arrives ready to use. Names come in three spellings, phone numbers in five formats, and the same company appears four times under slightly different names. Cleaning this by hand is tedious and easy to get wrong.

I use Python and Pandas to clean data reproducibly: every rule is written down in code, so the same steps can run again on next month's file. For teams that live in Excel, I automate repetitive work such as merging exports, splitting sheets, applying formatting and producing summary reports.

Business use cases

  • Deduplicating and merging lead lists from multiple sources
  • Standardising names, addresses, phone numbers and dates
  • Combining dozens of Excel or CSV files into one master dataset
  • Automated weekly or monthly Excel reports
  • Preparing data for CRM import or analysis

Example deliverables

  • Cleaned dataset in Excel or CSV
  • Summary of changes: rows removed, merged and corrected
  • Formatted Excel output with filters, frozen headers and consistent columns
  • Optional Python script to repeat the process

Frequently asked questions

Can you clean data I already have?

Yes. Send a sample and describe the problems, and I'll propose cleaning rules before processing the full file.

How do you find duplicates that aren't exact matches?

With normalisation (case, punctuation, legal suffixes) and fuzzy matching on names, domains and phone numbers, reviewed against a confidence threshold.

Can the automation run without Python installed?

Yes. Scripts can be packaged as Windows executables for colleagues who don't use Python.
