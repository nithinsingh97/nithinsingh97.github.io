How to Scrape E-commerce Product Data

How to scrape e-commerce product data reliably: category mapping, JSON-LD and product JSON, variants, images, prices and import-ready delivery.

NSNithin Singh Published 2026-11-148 min readE-commerce
Quick answer

To scrape e-commerce product data reliably, map the store's category and listing pages to collect every product URL, then extract each product from embedded structured data (JSON-LD or the store's product JSON) where available, falling back to HTML parsing. Expand variants into rows, collect image URLs, normalise prices and validate before delivery.

Map the store first

Start by understanding how the store is organised: the category tree, how listing pages paginate (page numbers, load more buttons or infinite scroll) and how product URLs look. Building a complete, deduplicated list of product URLs is half the job. Sitemaps (/sitemap.xml) often list every product and are a good cross-check.

Look for structured data before parsing HTML

Most modern stores embed machine-readable product data:

  • JSON-LD Product schema with name, SKU, brand, price, currency and availability, added for search engines.
  • Platform JSON: many store platforms expose product data as JSON, and many themes embed it in the page.
  • Background API calls visible in the browser's Network tab.
import json
from bs4 import BeautifulSoup

for tag in soup.select('script[type="application/ld+json"]'):
    data = json.loads(tag.string or "{}")
    if isinstance(data, dict) and data.get("@type") == "Product":
        offer = data.get("offers", {})
        print(data.get("name"), data.get("sku"), offer.get("price"))

Structured data is more accurate than visible text and survives redesigns better.

Handle variants deliberately

Decide early whether you need one row per product or one row per variant. Import tools usually want one row per variant, with a shared parent ID, a variant SKU, option values such as size and colour, and a variant price. Agree this format before extraction to avoid reshaping later.

Prices, currencies and stock

  • Store prices as numbers, not text. Strip currency symbols and thousands separators, and keep a separate currency column.
  • Capture both regular and sale price where shown.
  • Be aware that prices and availability can vary by region, cookies or logged-in state.

Images

Collect full-resolution image URLs rather than thumbnails. Many stores serve resized images through URL parameters. If you need the files, download them into folders named by SKU, and keep the original URL in your spreadsheet.

Validate before you deliver

Check for products with missing prices, duplicate SKUs, empty titles and broken image links. Compare the product count against the store's category counts or sitemap. For JavaScript-heavy stores, see Handling dynamic websites using Playwright.

Frequently asked questions

Can you scrape Shopify stores?

Many Shopify stores expose product data in a structured form, which makes extraction efficient. Each store is checked individually.

How do I monitor competitor prices?

Run the same scraper on a schedule, store each run with a date, and compare runs to flag price and stock changes.
