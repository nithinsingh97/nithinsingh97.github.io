Handling Dynamic Websites Using Playwright

How to scrape JavaScript-heavy websites with Playwright and Python: auto-waiting, infinite scroll, capturing JSON responses and faster, reliable runs.

NSNithin Singh Published 2026-11-149 min readTools
Quick answer

To scrape a dynamic website with Playwright, load the page in a headless browser, let Playwright's auto-waiting or explicit locators wait for the content, scroll or click to trigger loading, and, where possible, capture the JSON responses the page fetches instead of parsing the rendered HTML. Block images and fonts to speed things up.

Why dynamic sites break simple scrapers

On a dynamic site, the HTML you download is often an empty shell. The content arrives afterwards through JavaScript and background requests. Requests and BeautifulSoup see the shell; a real browser sees the content. Playwright gives you that browser, controlled from Python.

The basics

from playwright.sync_api import sync_playwright

with sync_playwright() as p:
    browser = p.chromium.launch(headless=True)
    page = browser.new_page()
    page.goto("https://example.com/listings", wait_until="domcontentloaded")
    cards = page.locator(".listing-card")
    cards.first.wait_for()                # wait until content exists
    for i in range(cards.count()):
        print(cards.nth(i).locator("h2").inner_text())
    browser.close()

Locators in Playwright wait automatically for elements to be ready before acting, which removes most timing problems. Avoid fixed sleep() calls. Wait for the thing you need.

Capture the JSON, not the HTML

The most useful Playwright technique for scraping is listening to network responses. If the page fetches its listings from an internal API, you can capture that clean JSON directly:

results = []
def on_response(resp):
    if "/api/search" in resp.url and resp.ok:
        results.extend(resp.json().get("items", []))
page.on("response", on_response)
page.goto(url)

This is faster and more accurate than reading visible text, and it often includes fields the page never displays.

Infinite scroll and load-more buttons

Scroll in a loop until no new items appear, or click load more until the button disappears. Always set a maximum number of iterations and stop when the item count stops growing.

prev = -1
while True:
    count = page.locator(".item").count()
    if count == prev: break
    prev = count
    page.mouse.wheel(0, 4000)
    page.wait_for_timeout(800)

Make it faster

  • Block heavy resources: route images, fonts and media to abort when you don't need them.
  • Reuse browser contexts: contexts are lightweight compared with launching new browsers.
  • Use the browser only where needed: once you know the API endpoint or detail-page pattern, plain HTTP is faster.

Make it reliable

  • Wrap each page in try/except, retry transient failures and save a screenshot on error.
  • Write results incrementally so a long run can resume.
  • Pace requests and run at sensible volumes. Respect the site.

For when to choose Playwright over alternatives, see Python vs Selenium vs Playwright.

Frequently asked questions

Is Playwright good for web scraping?

Yes. It is one of the best tools for JavaScript-heavy sites, thanks to auto-waiting, multi-browser support and network interception.

Can Playwright run headless?

Yes. Headless mode is the default for automated runs. Headed mode is useful for debugging.
