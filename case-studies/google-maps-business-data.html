The challenge

The client needed a list of businesses in a specific category across a wide area. A single broad search returns only a limited number of results, so most businesses would be missed, and overlapping searches create duplicates.

Technical approach

Search planningStep 1
ExtractionStep 2
EnrichmentStep 3
CleaningStep 4
DeliveryStep 5
  1. Search planning: Split the target area into cities and postcodes (or map grid points for dense areas) and built one query per area and keyword combination.
  2. Extraction: Used a Playwright-based browser workflow to load each search, scroll the results panel, and open each listing to capture the publicly displayed fields.
  3. Enrichment: Visited each business website, where one was listed, to collect publicly published email addresses and social profile links.
  4. Cleaning: Normalised phone numbers and addresses, then deduplicated on listing URL, phone and normalised name plus address.
  5. Delivery: Delivered a sample for column approval, then the full Excel file with one row per business and a source URL for each.
