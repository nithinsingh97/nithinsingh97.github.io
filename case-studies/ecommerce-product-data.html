The challenge

The client needed every product from an online store, including all size and colour variants, prices, images and specifications, in a format that could be imported into their own catalog system.

Technical approach

Site mappingStep 1
Structured data firstStep 2
Variant handlingStep 3
ImagesStep 4
ValidationStep 5
  1. Site mapping: Crawled the category tree and listing pages to build a complete, deduplicated list of product URLs.
  2. Structured data first: Checked each product page for embedded JSON-LD and internal product JSON, which carry cleaner prices, SKUs and variant data than the visible HTML.
  3. Variant handling: Expanded each product into one row per variant with a shared parent ID, so the file matched the import template.
  4. Images: Collected full-resolution image URLs and optionally downloaded them into folders named by SKU.
  5. Validation: Checked for missing prices, duplicate SKUs and broken image links before delivery.
