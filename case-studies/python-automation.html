The challenge

A team was spending time every day logging into a web portal, downloading several reports, and merging them in Excel into one summary sheet.

Technical approach

Process mappingStep 1
Browser automationStep 2
Data processingStep 3
ReliabilityStep 4
PackagingStep 5
  1. Process mapping: Recorded each manual step and the exact output the team expected.
  2. Browser automation: Automated login and downloads with Playwright, with credentials read from a local environment file rather than the code.
  3. Data processing: Merged and cleaned the downloaded files with Pandas and wrote a formatted Excel summary.
  4. Reliability: Added logging, error screenshots and clear failure messages.
  5. Packaging: Packaged the script as a Windows executable and scheduled it with Task Scheduler.
