The challenge

The client had a large batch of PDF documents with tables in similar but not identical layouts. Copying them manually would have taken weeks, and some pages were scanned images.

Technical approach

TriageStep 1
Table extractionStep 2
OCRStep 3
TraceabilityStep 4
ExceptionsStep 5
  1. Triage: Classified every file and page as text-based or scanned, and grouped files by layout.
  2. Table extraction: Used pdfplumber with position-based rules to rebuild table rows and columns for each layout group.
  3. OCR: Ran OCR on scanned pages and applied validation rules, such as totals and date formats, to catch misreads.
  4. Traceability: Added file name and page number to every output row.
  5. Exceptions: Produced a separate report of pages that could not be parsed confidently, for manual review.
